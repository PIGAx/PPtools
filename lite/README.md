# 槓桿部位工具（PPtools 精簡版）

新金鑽等槓桿商品的部位控管與庫存戰情室，可直接用瀏覽器開啟。

- **部位控管**：記錄每一筆成交（現股／槓桿倍數），自動計算停損價、下跌緩衝、整體槓桿與壓力測試；緩衝低於預警門檻時頁面頂端會出現警示，也可以設定自己的 Telegram Bot 收通知。
- **庫存戰情室**：同一份庫存的視覺化損益與槓桿。

## 資料存在哪裡？

所有資料只存在你自己裝置的瀏覽器（localStorage），不會上傳到任何伺服器，其他人看不到。
換裝置或清除瀏覽器資料前，請用右上角「匯出備份」存成檔案，之後在新裝置「匯入」即可。
Telegram Bot Token 也只存在該裝置，不會出現在備份檔裡。

## 報價

GitHub Actions 每個交易日收盤後抓台股全市場與 `data/us-symbols.json` 列出的美股收盤價，寫進 `data/quotes.json`；
清單外的標的會在頁面上改用 Yahoo Finance 即時抓取。
