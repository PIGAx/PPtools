📨 Telegram 停損通知設定

設定好之後，每次打開「部位控管」更新報價時，只要有槓桿部位離停損價太近，手機就會收到 Telegram 通知。大約 5 分鐘可以完成，每個人用自己的 Bot，彼此看不到。

1建立自己的 Bot，拿到 Token

  1. 打開 Telegram，搜尋 @BotFather（有藍色勾勾的官方帳號），按「Start」。
  2. 傳送 /newbot。
  3. 輸入 Bot 的顯示名稱，隨意取，例如「我的停損通知」。
  4. 輸入 Bot 的帳號名稱：必須以 bot 結尾、不能和別人重複，例如 amy_stop_bot。
  5. 成功後 BotFather 會回一段訊息，裡面有一串像 1234567890:AAH… 的文字，這就是 Bot Token。
    直接點一下那串灰底文字就會自動複製，不要用手打，l（小寫 L）和 I（大寫 i）很容易看錯。

2先跟你的 Bot 說一句話

  1. 點 BotFather 回覆裡的連結 t.me/你取的帳號名稱，進到你自己的 Bot。
  2. 按「Start」，再隨便傳一句，例如 hi。

這步一定要做，Bot 不能主動傳訊息給沒跟它說過話的人。Bot 不會回你，這是正常的。

3查自己的 Chat ID

  1. 用瀏覽器打開下面這個網址，把 <Token> 換成第 1 步複製的 Token（<> 也要拿掉）： 
    https://api.telegram.org/bot<Token>/getUpdates
    注意 bot 要緊貼在 Token 前面，中間沒有空格或斜線。
  2. 畫面上找 "chat":{"id": 後面的那串數字，例如： 
    "chat":{"id":123456789,"first_name":"Amy","type":"private"}
    這串數字就是你的 Chat ID。

4填進「部位控管」並測試

  1. 打開 槓桿部位工具 的「部位控管」，往下找到「帳務計算與風險控管」裡的 📨 Telegram 停損通知，點開。
  2. Bot Token：貼上第 1 步的 Token。Chat ID：填第 3 步的數字。
  3. 填完點一下欄位外面，設定才會存起來。
  4. 勾選「報價更新後，緩衝低於門檻就發通知」，標題會變成「（已啟用）」。
  5. 按 「傳送測試訊息」，手機收到「✅ PPtools 停損通知測試成功…」就完成了。

想調整多近才通知，改上方的「停損預警門檻（緩衝 < %）」，預設 10%：離停損價不到 10% 就通知。

🔒 Token 不要給任何人 拿到 Token 的人就能用你的 Bot 傳訊息。不要貼在聊天群組、不要傳給其他 Bot。萬一外流，對 @BotFather 傳 /revoke 換一組新的，再回到部位控管把 Token 改成新的即可（Chat ID 不用改）。
Token 只存在你這台裝置的瀏覽器，不會上傳、也不會出現在「匯出備份」的檔案裡；手機和電腦都要通知的話，兩邊各填一次。

什麼時候會收到通知？

  • 打開「部位控管」、報價更新完（每天第一次打開會自動更新，也可以按「🔄 更新報價」），有槓桿部位離停損價小於門檻就發。
  • 同一筆每天最多通知一次；如果之後真的跌破停損價，會再發一次。
  • 網頁沒打開時不會檢查，建議每天收盤後打開看一下。

遇到問題

看到的訊息原因與解法
Unauthorized 或 401Token 不對：可能打錯一個字，或已經 /revoke 過。到 @BotFather 傳 /mybots → 選你的 Bot → API Token，點選複製最新的那組。
{"ok":true,"result":[]}Token 是對的，但 Bot 還沒收到訊息。回 Telegram 對你的 Bot 再傳一句 hi，重新整理網頁。
chat not foundChat ID 填錯，或還沒對你的 Bot 按過 Start（第 2 步）。
Token 後面多了 15:43 之類的時間從 Telegram 複製時把訊息時間也帶進來了，刪掉。Token 冒號後面固定是 35 個字元。
按了測試沒反應、標題還是「（未啟用）」填完欄位要點一下外面才會存；也要勾選「報價更新後…就發通知」。
